# Source-grounded acceptance matrix

These are replacement acceptance cases, not a command to copy upstream tests unchanged. Upstream fixtures explain mechanisms; cases marked **new** require Laser-specific tests because upstream does not satisfy the product contract. The entire LEAP remains subject to the visual/browser and interaction acceptance criteria in the [live experience](../agents-live-experience.md).
