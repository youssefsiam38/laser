# Laser 0.14.0

## Clearer tool results

- Tool errors distinguish what was saved from what was refused, and explain what to do next.
- Preview results reuse the same review surface as the action they describe.
- Agent and Command tools follow a shared, validated contract with bounded inputs and consistent recovery guidance.

## Reliability

- Recorded tool evaluations check schema handling, retries, result truncation and recovery across model profiles.
- Stronger validation catches incomplete tool definitions before they ship.

Project lifecycle work is not included in this release.
