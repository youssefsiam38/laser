Laser 0.7.3

## Large outputs read like output

### Improved in 0.7.3

- A long command output now stays inside its tool block. You see its first lines, then a quiet "Show full output · 93 KB", instead of a grey box saying part of it is not kept.
- The full output opens as output: the tool and its command at the top, the text itself with real line breaks and colours, lines wrapped by default, and Find, Copy and Download .txt at the bottom. No more raw data on one long line.
- It scrolls continuously through the whole output, however large, while keeping only the part you are reading in memory.
- Output from a command that just finished can be opened right away. You no longer need to reopen the conversation to read all of it.
